# Helldivers 2 playtests

What each layout felt like, newest first.

## default, not yet played

Written 2026-10-21 from the game's default keys, which the owner's settings file has not
changed. To judge on the first drop:

1. **Stratagems**: hold the pinky's resting key and enter a code on the stick. Is a stick
   direction a clean single press, or does it repeat or miss?
2. **Dive** on the lower thumb key, beside the stick: reachable while moving?
3. **Windows shortcuts.** Sprint then dive is Shift then Alt, dive then map is Alt then
   Tab, and a stratagem while sprinting is Ctrl and Shift. Does any of them switch the
   input language or leave the game?
4. **What is missing** that the hand reached for the keyboard to get.
