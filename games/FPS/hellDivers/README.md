# Case study: Helldivers 2

One unit on the left hand, with a mouse in the right (`dist/FPS/hellDivers/`): the mouse
aims, which a keyboard-mode stick cannot do well. Not yet played.

The repo does not write this game's key file, so the layout sends the game's own default
keys. Check them in the game's controls screen, and change a key in this folder's
`actions.yaml` if the game has an action somewhere else.
