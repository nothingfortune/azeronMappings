# Ace Combat 7 playtests

What each layout felt like, newest first.

## default pair, not yet flown

Written 2026-10-21 from the game's published default keys; the game was not installed.
First, in Options > Keyboard: do the keys in `actions.yaml` match? Then fly:

1. **Push the right stick up. Does the nose go down?** If it goes up, the game is set to
   inverted pitch; change that in the game, not the layout.
2. **Push the right stick right. Does the plane roll right?** The right unit's stick is
   mounted rotated; if it rolls left, say so.
3. **A high-G turn** is both throttle keys held with pitch up. A stick sends one direction
   at a time, so the left index's top key sends decelerate on its own: left stick up,
   that key, and the right stick down. Does the game take it as a high-G turn? Do not
   use that key while braking with the stick pulled down: both send S, so letting go of
   either stops the brake.
4. **Gun and missiles together** send Ctrl+Space. With an input method installed, does
   that swallow the missile?
